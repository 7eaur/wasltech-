# Wasl Social Poster System

حزمة متكاملة لبناء نظام تصميم وتسويق قابل لإعادة الاستخدام للعلامات التقنية وخدمات الحلول الرقمية.

## محتويات الحزمة

- `SKILL.md`: المهارة القابلة لإعادة الاستخدام داخل Manus، وتشمل منهج التصميم والتسويق والبحث والمراجعة.
- `marketing-campaign.md`: الخطة التسويقية الشاملة لوصل تك، بهدف نمو المتابعين وجذب العملاء، مع خمسة أيام نشر أسبوعيًا.
- `design-system.md`: قواعد التصميم الأخيرة، بما فيها الخلفية النظيفة، وضع الشعار أعلى اليمين، شريط التواصل السفلي، نظام القوالب، وقاعدة استخدام CTA.
- `examples/`: آخر أربعة أمثلة تصميمية تم إنتاجها لتوضيح النظام بصريًا.

## الأمثلة

1. `01-clean-awareness-post.png`: منشور توعوي بدون CTA كبير، يعتمد على الهوك والعنصر البصري وشريط التواصل.
2. `02-clean-conversion-post.png`: منشور تحويلي مع CTA واضح لدعوة صاحب الفكرة إلى التواصل.
3. `03-clean-minimal-awareness.png`: منشور نظيف يربط جودة المشروع بوضوح حضوره.
4. `04-clean-minimal-idea.png`: منشور يحول فكرة أولية إلى واقع بصري مع CTA.

## مبادئ النظام

يعتمد النظام على قاعدة:

> **هوية ثابتة + قوالب متعددة + هوك مختصر + تغذية بصرية مرتبطة بالرسالة + CTA عند الحاجة فقط.**

لا يحتاج كل منشور إلى زر CTA. منشورات الوعي والتعليم تركز على جذب المتابعين والحفظ والمشاركة، بينما تستخدم منشورات التحويل CTA محددًا مثل «شاركنا فكرتك» أو «أرسل كلمة ابدأ».

## الاستخدام

عند إنشاء منشور جديد، حدد أولًا هدفه، ثم اختر القالب المناسب، واكتب ثلاثة هوكات على الأقل، وحدد هل يحتاج CTA داخل التصميم أم يكفي شريط التواصل السفلي. راجع التصميم بحجم الهاتف قبل النشر، ولا تستخدم أرقامًا أو نتائج أو شهادات غير موثقة.
