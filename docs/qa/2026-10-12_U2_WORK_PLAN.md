# U2 — خطة تنفيذ تجربة الخدمات والتواصل

الفرع المستقل: `fix/independent-site-recovery-20261010`.

1. تطوير المواقع كنموذج: تقديم المخرجات والأعمال المرتبطة في أعلى تسلسل الخدمة، دون حذف الأقسام الأخرى.
2. صفحة التواصل: مساران واضحان بعد الهيرو، سؤال سريع عبر واتساب أو بدء مشروع، مع إبقاء البريد ووسائل الاتصال.
3. اختبار البناء والروابط والوصولية والتجاوب بالعربية والإنجليزية.
4. عدم تعميم نموذج الخدمة حتى اعتماد المعاينة بصريًا؛ عدم تغيير main أو Production.

هذا المستند يحدد خطة التنفيذ ولا يثبت اكتماله.
