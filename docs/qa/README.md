# Wasl Tech VNext — QA Evidence

This folder stores dated, evidence-focused phase/release reports.

Naming:
`YYYY-MM-DD_<phase>_<scope>.md`

QA reports record:
- exact branch/SHA;
- routes/viewports/states checked;
- commands/workflows;
- screenshots/artifacts;
- failures found;
- fixes applied;
- final gate status.

QA files are evidence, not project status.

Current status belongs only in:
- `PROJECT_STATUS.md`
- `PROJECT_HANDOFF.md`

Do not create a new QA report for trivial edits.
