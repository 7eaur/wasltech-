## 2. قاعدة ملكية نية البحث

**كل نية لها صفحة أساسية واحدة:**
- الرئيسية `/` و`/en/`: **هوية العلامة وحزمة الخدمات** («وصل تك / Wasl Tech»؛ «وصلتك» تهجئة بديلة).
- دليل `/services/` و`/en/services/`: استكشاف الثماني خدمات ومقارنة الأنواع؛ ليس منافسًا لصفحة تصميم المواقع عند طلب الخدمة مباشرة.
- تفاصيل خدمة `/services/<slug>/`: **نية الاستفسار التجاري**؛ لا نكرر فقرة «نصمم كل شيء» لجميع الصفحات.
- المشروع `/portfolio/<slug>/`: **نية دليل الخبرة/نوع المشروع**؛ اسم العمل أولًا ثم طبيعة الحل، والتفاصيل المثبتة فقط.
- المقال `/insights/<slug>/`: **نية معلوماتية أو مقارنة/تخطيط**، مع رابط داعم واحد على الأقل للخدمة المعنية حين يلائم.
- صفحة من نحن `/about/`: تعريف الفريق والهُوية والمصداقية؛ تواصل `/contact/`: طرق التواصل وتحديد الخدمة، لا صفحة تروّج لكل كلمة تجارية.

## 4. المجالات التي تحتاج تمييزًا حقيقيًا

1. **مواقع / متاجر:** الموقع يقدم محتوى وخطوات تواصل، والمتجر يتضمن كتالوجًا وطلبات ودفعًا/تسليمًا؛ لا تستهدف صفحة المواقع «إنشاء متجر إلكتروني» كـprimary.
2. **أنظمة مخصصة / حلول تقنية:** النظام منتج تشغيلي ذو مستخدمين وصلاحيات وقاعدة بيانات؛ الحل التقني قد يكون ربط نظام قائم وأتمتة جزء منه. يلزم مثال موثّق مميز لكل صفحة.
3. **هوية بصرية / بروفايل الشركة:** الهوية نظام تصميم وشعار، والبروفايل وثيقة عرض محتوى وخدمات؛ لا تُكرر نفس CTA/الحزمة باعتبارهما نفس الشيء.
4. **خدمة / دراسة حالة:** يمكن ذكر عبارة «تطوير تطبيق» في وصف مشروع Aroma Cafe، لكن لا يصبح المشروع هو الصفحة الرئيسية لطلب برمجة التطبيقات. الثقة تأتي من قرار التنفيذ والنتائج الموثقة.
5. **علامة Wasl Tech / أسماء مشابهة:** نتائج «وصلك» و«موقع وصلك» قد تخص جهات غير ذات صلة. استخدم «وصل تك / وصلتك» مرة في سياق صحيح، ولا تضف أسماء متشابهة كحيلة كلمات.
