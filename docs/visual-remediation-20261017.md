## أسباب بنيوية تأكدت من مراجعة المصدر
- `scripts/build.mjs` يبني CSS عامًّا ثم حزماً منفصلة للعائلات. لذلك حلول override في آخر ملف دون فهم ترتيب التحميل ليست مقبولة.
- `src/pages/project-detail.js` يفصل story وscope وservices في أقسام متتابعة؛ يجب تعديل المكونات/التخطيط الأصلي عند تصحيح الكثافة.
- `src/pages/process.js` يخرج أربع `process-phase` داخل `process-phases__list`؛ اتصالها البصري يقع في CSS الأساسي `src/styles/about-process.css`.
- `scripts/check-project-details.mjs` يشترط ثلاثة أقسام story ومحتوى scope؛ لا تُحذف لحل طول الصفحة.
- `scripts/check-quality.mjs` يفرض سقف CSS gzip قدره 16 KiB للصفحة؛ الحل الصحيح تحسين CSS وإزالة الزائد وليس تعطيل الفحص.
- README يقول إن main مصدر النشر، لذا هذا العمل معزول في فرع مستقل إلى اجتياز الفحص.
